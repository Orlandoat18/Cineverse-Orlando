# 🎬 CineVerse

Portal web de reserva de entradas para un cine, desarrollado como práctica de JavaScript.

El proyecto permite gestionar información del usuario, calcular el precio de una reserva, aplicar descuentos e IVA, activar una promoción con cuenta atrás y publicar reseñas que permanecen guardadas en el navegador.

---

## 📋 Descripción

CineVerse es una aplicación web desarrollada con **HTML, CSS y JavaScript**.

El objetivo principal es aplicar diferentes conceptos de JavaScript relacionados con:

- Manipulación del DOM.
- Parámetros de URL.
- Fechas y horas.
- Información del navegador.
- Operadores de asignación lógica.
- Conversión y cálculo de números.
- Formateo de moneda.
- Temporizadores.
- Eventos.
- `localStorage`.
- Manipulación segura del contenido del DOM.

---

CineVerse es un portal web de reserva de entradas desarrollado con HTML, CSS y JavaScript como práctica de desarrollo web. 
La aplicación permite gestionar la información del usuario y su sesión, calcular el precio de las entradas aplicando descuentos e IVA, 
mostrar el resumen de compra en euros, activar una promoción de venta anticipada mediante una cuenta atrás de 20 segundos y publicar reseñas. 
Las reseñas se almacenan en localStorage para mantenerlas después de recargar la página y se muestran de forma segura mediante la manipulación del DOM y textContent. 
El proyecto está organizado en los archivos index.html, styles.css y app.js, y se gestiona mediante Git y GitHub.
